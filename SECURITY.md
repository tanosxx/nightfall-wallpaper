# Безопасность

Текущий поддерживаемый выпуск — **Nightfall v15 для GNOME Shell 50**. Сообщая о проблеме в более ранней сборке, по возможности проверьте её на актуальном выпуске.

## Сообщить об уязвимости

Если в разделе [Security](https://github.com/tanosxx/nightfall-wallpaper/security) доступна кнопка **Report a vulnerability**, отправьте приватный отчёт через неё. Наличие этого канала зависит от настроек репозитория.

Если приватная отправка недоступна, создайте issue с просьбой предоставить канал для сообщения об уязвимости, без кода эксплуатации, секретов и подробностей, позволяющих повторить атаку. Адрес электронной почты для подобных сообщений здесь не опубликован.

В приватном отчёте полезны версия, окружение, затронутый компонент, минимальные шаги воспроизведения и описание последствий. Не присылайте рабочие токены, персональные файлы и полные дампы пользовательских настроек. Фиксированное время ответа не обещается.

## Граница доверия

Нативная часть Nightfall исполняется внутри **GNOME Shell**. Это не песочница браузера: произвольный код расширения имеет возможности процесса пользовательского сеанса и может нарушить его работу.

В v15 сцены поставляются вместе с расширением. Приложение не загружает и не исполняет сцены сообщества из сети. Будущие скачиваемые пакеты не следует считать безопасными только потому, что они размещены на GitHub или имеют контрольную сумму.

Используйте релизы и исходники из [репозитория проекта](https://github.com/tanosxx/nightfall-wallpaper). `SHA256SUMS` помогает проверить целостность загрузки; контрольная сумма сама по себе не заменяет доверие к источнику публикации.

## При разработке

- Не включайте токены, пароли, локальные настройки или личные файлы в Git, ассеты и материалы GitHub Pages.
- Проверяйте пути, состав архива, ограничения ресурсов и совместимость перед установкой пакета.
- Обсуждайте изменения загрузчика, установщика, сетевого доступа и границ исполнения отдельно от художественных правок сцены.
- Исправление уязвимости должно описывать затронутые версии и способ обновления. Не публикуйте секреты в тестах и примерах.

Порядок обычных исправлений описан в [CONTRIBUTING.md](CONTRIBUTING.md).
