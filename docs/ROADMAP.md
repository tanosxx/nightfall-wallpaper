# Дальнейшее развитие

## Доступно в v16

- Общий JSON-каталог на GitHub Pages для приложения и сайта.
- Отдельные проверяемые пакеты семи сцен в GitHub Releases.
- Скачивание, обновление, установка из ZIP, выбор и удаление локальных сцен.
- Работа установленных сцен без сети и сохранённая копия каталога.
- Небольшое приложение с одной встроенной сценой; перенос прежней коллекции при обновлении.
- Формат пакета, шаблон и проверяемый процесс участия через pull request.

Произвольный код из пакета не исполняется. Новые ID могут использовать один из включённых движков; новые эффекты и геометрия требуют изменения и проверки самого приложения.

## Следующие направления

- Удобный редактор расположения эффектов и универсальный движок для новых композиций.
- Предпросмотр и обсуждение присланных работ перед включением в общий каталог.
- Отдельный интерфейс отправки работы, использующий GitHub, если он упростит процесс pull request.
- Проверка других версий GNOME и оптимизация нагрузки на больших экранах.

Это направления работы, а не обещание сроков. Поддержка рабочего стола сейчас заявлена только для GNOME Shell 50. Прямая загрузка чужого исполняемого кода в GNOME Shell не планируется без отдельной изоляции.
